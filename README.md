# 惯性镜头（Inertial Lens）

单目视觉 + IMU 联合估计的手持"惯性镜头"跟踪器。GPU 无关，纯 TypeScript 实现，
所有计算在浏览器 / Node 内完成：**界面上的每一条轨迹、每一个残差都由惯性镜头内核
（`src/lens/kernel.ts`）实时算出，而不是回放的预录曲线。**

## 界面怎样启动

```bash
npm install
npm run dev
```

终端会打印 `Local: http://127.0.0.1:5173/`。在浏览器打开该地址，页面加载时会：

1. 用仿真轨迹生成器渲染一段带噪声的 320×240 手持序列（进度条显示渲染进度）；
2. 运行跟踪器提取角点与光流，构建 `SensorSession`（时间戳图像 + 陀螺/加计原始样本）；
3. 调用 `kernel.bootstrap()` 完成初始化（外参、时差、陀螺偏置、多视图平移 SfM 求尺度）；
4. 调用 `buildUI()` 启动镜头跟踪窗口。

点击 **▶ 开始惯性镜头** 播放；**⏸暂停 / ⏭单步 / ↺复位** 控制回放；
**惯性辅助** 开关在内核里直接启用/禁用惯推（`useInertialPropagation`）。
失败反馈会写回内核并在事件日志中显示（例如陀螺-视觉失配会放大偏置协方差）。

生产构建与本地预览：

```bash
npm run build      # tsc --noEmit && vite build
npm run preview    # 预览 dist/
npm test           # vitest 全量（23 项，约 3 分钟）
```

## 窗口里能看到什么

- **镜头画面**：当前 RGB 帧 + 绿色跟踪点；固定的虚拟标记（青色环 = 估计投影，
  品红十叉 = 真值投影）随镜头移动检查稳定性，并显示二者像素差。
- **残差面板**：使用/跟踪点数、剔除数、重投影 RMS/P95、光流残差、旋转残差、
  位置/姿态 sigma、陀螺/加计偏置、地标数、重定位次数。
- **轨迹图**：x-y 俯视，绿色 = 估计，灰色虚线 = 真值，橙色 = 留出帧（未参与优化），
  蓝色 = 当前位置。
- **可观测性台账**：列出哪些量被可靠恢复、哪些没有依据（尺度、重力方向、平移）。
- **事件日志**：状态迁移（tracking → inertial → lost）、视觉丢失、偏置放大等。

## 架构

| 路径 | 职责 |
| --- | --- |
| `src/sim/trajectory.ts` | 生成轨迹、噪声图像与机体系陀螺/加计 |
| `src/vision/` | 场景渲染、Harris 角点、KLT 光流、描述子匹配 |
| `src/estimation/eskf.ts` | 15 维误差状态卡尔曼滤波（位置/速度/姿态/陀螺偏置/加计偏置） |
| `src/lens/bootstrap.ts` | 陀螺姿态链 + 多视图平移 SfM（Schur 补线性求解）+ 尺度拟合 |
| `src/lens/kernel.ts` | 镜头内核：跟踪、惯推、视觉更新、重定位、失败反馈、留出帧 |
| `src/lens/replay.ts` | 浏览器/测试共享的采集管线（`buildCapture`） |
| `src/ui/main.ts` | 镜头跟踪窗口（原生 DOM + Canvas） |
| `tests/` | 端到端、标定、反作弊、数学/视觉单元测试 |

## 关键约定

- 载体：x 前、y 左、z 上；相机：x 右、y 下、z 前。
- `R_bc` 将相机坐标映射到机体系；相机中心 `C = p_wb + R_wb · t_bc`。
- 陀螺为机体系角速度；姿态传播 `R_wb(k) = R_wb(k-1) · ΔR`。
- 视觉两视图相对旋转 `rel.R = R_bcᵀ · ΔRᵀ · R_bc`，与 `relativeRotationCamera` 一致。

## 反作弊

- 仿真器与估计器完全解耦：内核只接收 `SensorSession`（图像轨迹 + 原始 IMU）。
- `tests/anti_cheat.test.ts` 篡改真值后估计结果差异 < 1e-9，证明估计不读真值。
- 每段留出帧（`holdout`）从不参与视觉更新，其误差单独报告，接受与在线误差同量级的检验。
- 平滑但错误的轨迹会被对齐后的 ATE 暴露（尺度落在 0.7–1.4 之外即判定失败）。

## 已知限制

- 单目 + 低频 IMU 下，尺度仅在视觉-惯性一致性成立时可恢复；无视觉或纯旋转段不可观。
- 重力方向由加计静态窗口估计，长时间纯视觉丢失期间会随偏置漂移。
- 无浏览器可用时只能通过 `npm run build` 与无头测试验证计算路径；视觉呈现需人工确认。
